# Contributing to Hologram Studio

Thank you for your interest in contributing to **Hologram Studio**!

## How You Can Contribute
- **Report Bugs:** Open an issue with your browser, OS, GPU details (important for WebGL/Three.js rendering), and steps to reproduce.
- **Suggest Features:** Share ideas for new holographic shaders, card presets, export formats, or UI improvements.
- **Submit Pull Requests:** Fix bugs, optimize rendering performance, or add new visual features.
