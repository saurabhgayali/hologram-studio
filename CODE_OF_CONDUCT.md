# Contributing to Hologram Studio

Thank you for your interest in contributing to **Hologram Studio**!

## How You Can Contribute
- **Report Bugs:** Open an issue with your browser, OS, GPU details (important for WebGL/Three.js rendering), and steps to reproduce.
- **Suggest Features:** Share ideas for new shader effects, card presets, export formats, or UI improvements.
- **Submit Pull Requests:** Fix bugs, optimize rendering performance, or add new visual features.

## Local Development Setup
1. Fork the repository and clone your fork locally.
2. Install dependencies (if applicable) or serve the root directory using a local static server.
3. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Test your changes across desktop and mobile viewports to ensure smooth WebGL frame rates.
5. Commit your changes with clear messages and open a Pull Request.

## Pull Request Guidelines
- Keep changes focused and modular.
- Avoid introducing heavy external dependencies unless strictly necessary.
- Include a screenshot or short screen recording for any visual or shader changes.
