Holo-Deck

A render-target volumetric hologram for three.js — how it works, and how to project your own GLB onto any surface in your own scene.

← Open the live demo

1. The core idea

A hologram panel is really two scenes and two cameras. The content you want to appear "inside" the panel never lives in your visible scene — it lives in a hidden scene that is rendered into a texture, and that texture is painted onto a flat surface with a shader that makes it look like light rather than paint.

  hidden scene            render target            visible scene
  ┌──────────────┐        ┌────────────┐          ┌────────────────────┐
  │  your GLB    │  ───►  │  1024×1024 │  ───►    │  card frame        │
  │  lights, fx  │ render │  texture   │  uMap    │  ├ panel mesh ─────┼── hologram shader
  │  hidden cam  │        └────────────┘          │  └ glass cover     │
  └──────▲───────┘                                └─────────▲──────────┘
         └──────── angle mirrored every frame ──────────────┘
                     (this is what creates real depth)

Why it looks volumetric

A static texture on a plane is a sticker — turn your head and it stays flat. Every frame the projector takes your main camera position, converts it into the panel's local space, and places the hidden camera on a sphere of the same direction around the hidden content. Orbit the card 30° to the left and the hidden camera also swings 30° to the left, so you literally see the far side of the model through the window. That parallax is the whole trick.

2. Pipeline, step by step

  1. Hidden scene — new THREE.Scene() holding your model, lights, dust/starfield particles and optional fog. It is never added to your visible scene.
  2. Hidden camera — a PerspectiveCamera orbiting at a fixed radius (distance), always looking at the origin.
  3. Render target — a WebGLRenderTarget (1024², HalfFloatType, 4× MSAA). Once per frame: setRenderTarget(rt) → clear() → render(hidden, hiddenCam) → setRenderTarget(previous). Restoring the previous target matters, otherwise you break post-processing chains.
  4. Hologram material — a ShaderMaterial sampling that texture, transparent, depthWrite:false, AdditiveBlending, toneMapped:false.
  5. Surface — any mesh with UVs. In the demo it is a plane recessed inside a metallic card body, with a faint glass sheet in front and a point light in front of the window so the hologram appears to spill light into the room.

Gotcha: colour space

Built-in materials get an automatic linear→sRGB conversion at the end of the shader. A raw ShaderMaterial does not. That is why the fragment shader ends with an explicit pow(col, vec3(1.0/2.2)) — without it, the projection looks nearly black.

3. What the shader does

EffectTechnique
Glitch bandsRows are quantised into 90 bands; a hashed random per band and time-step shifts uv.x, scaled by uGlitch.
Chromatic splitR and B are sampled at ±ca horizontal offsets from G — cheap prism fringing.
Spectral tintLuminance-weighted mix toward uTint, so bright areas stay hue-correct instead of clipping to white.
Scanlinessin(uv.y * 620 - time * 9 * uScanSpeed) multiplied over the colour, plus a slow rolling sweep band.
Fresnel edge glowpow(1 - dot(normal, viewDir), 2.5), added to the colour and to alpha so grazing angles bloom.
FlickerPer-frame hashed brightness dip, scaled by uGlitch.
AlphaDerived from luminance + fresnel × uOpacity, so dark parts of the hidden scene become genuinely transparent instead of grey.

4. Quick start for your own project

Copy holo-projector.js (and optionally presets.js) into your project. It needs three.js and GLTFLoader — nothing else, no build step required.

import * as THREE from 'three';
import { HoloProjector } from './holo-projector.js';

const holo = new HoloProjector({ renderer });

// 1. what to project — any Object3D, or a GLB URL
await holo.loadGLB('/models/robot.glb');   // auto-centered + auto-scaled
// holo.setContent(myObject3D);

// 2. where to project it — ANY mesh in your scene
const panel = new THREE.Mesh(new THREE.PlaneGeometry(2, 3), holo.material);
scene.add(panel);
holo.attachTo(panel);          // parallax anchor

// 3. once per frame, BEFORE your main render
function loop() {
  const delta = clock.getDelta();
  holo.update(camera, delta);
  renderer.render(scene, camera);
  requestAnimationFrame(loop);
}

Any surface

holo.material is an ordinary material. Put it on a curved panel, a cylinder, a phone screen model, a portal ring — anything with UVs.

Any model

loadGLB() fits the model into the hidden frustum automatically. Use { fit: false } to keep authored scale.

Many projectors

Create one HoloProjector per display. Each owns its own hidden scene, render target and material.

6. Recipes

Custom hidden scene instead of the built-in lights

holo.removeDefaultLights();
holo.scene.fog = new THREE.FogExp2('#04121c', 0.03);
holo.scene.add(new THREE.HemisphereLight(0x88ddff, 0x220044, 2));

Upload from a file input, safely

import { createValidatedModelURL } from './holo-projector.js';

input.onchange = async () => {
  const res = await createValidatedModelURL(input.files[0]);
  if (!res.ok) return showError(res.error);
  try { await holo.loadGLB(res.url); } catch (e) { showError(e.message); res.revoke(); }
};

Animate presets or your own content

import { createGalaxy } from './presets.js';
const galaxy = createGalaxy({ color: '#4dff88' });
holo.setContent(galaxy.object, { fit: false });
// in your loop:
galaxy.update(delta, elapsed, { autoRotate: true });

7. Performance & cleanup

  • The hidden scene is a full extra render pass each frame — keep it lean, and use setResolution(512) on low-end devices.
  • Skip holo.update() when the panel is off-screen or occluded; the last frame stays in the texture.
  • Every swap goes through clearContent(), which disposes geometries, materials and textures of content the projector owns.
  • Always revoke blob URLs (res.revoke()) after replacing an uploaded model.
  • Call holo.dispose() when the view unmounts — render targets are not garbage collected.

8. Troubleshooting

SymptomCause
Panel is blackMissing manual sRGB conversion in a forked shader, or no lights in the hidden scene.
No depth when orbitingattachTo() was never called, or parallax: false.
Hologram washes out to whiteAdditive blending over a bright background — set additive: false or lower opacity.
Invalid typed array lengthTruncated/corrupt GLB. Route uploads through createValidatedModelURL().
Panel hidden behind other transparencyAdditive + depthWrite:false is order-sensitive; set renderOrder on the panel mesh.
